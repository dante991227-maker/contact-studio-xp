# 拾联 · Contact Studio

个人极限编程通讯录项目。React + TypeScript + Vite，使用浏览器 localStorage 保存数据。

## 运行

需要 Node.js 22 或更高版本。

```bash
npm ci
npm run dev
```

终端显示的地址用于本地调试。生产构建和测试：

```bash
npm test
npm run build
```

将 `dist/` 部署到静态托管平台即可访问，无需后台服务。

## 功能

- 新增、编辑、删除、查看联系人，按姓名、公司、备注和联系方式搜索。
- 收藏/取消收藏，收藏筛选，列表中收藏优先。
- 单个联系人可添加任意多个电话、邮箱、社交账号和地址。
- 下载 `.xlsx` 模板、导入 `.xlsx`、导出全部联系人。
- 导入先校验整份文件，通过后确认追加；重复联系人也会新增，不覆盖已有记录。
- 本地保存失败时提示错误；检测到损坏的数据时禁止写入，避免覆盖原数据。

## Excel 约定

第一张工作表，表头顺序必须为：`姓名、公司、收藏、电话、邮箱、社交账号、地址、备注`。

每位联系人一行，每类信息一列。同一类有多项时使用 JSON 文本数组，例如 `["00123456789","+86 13800000000"]`。也兼容单元格中换行分隔的文本。收藏填写“是”或“否”。姓名必填，邮箱需要符合基本格式。手动填写电话时请把单元格格式设置为文本。

先点击“模板”下载空表；`docs/example-contacts.xlsx` 为浏览器实际导出的虚构联系人样例。单次导入不超过 5 MB / 5000 行。导出为字符串单元格，不把联系人文本作为 Excel 公式。

## 数据边界

数据保存在当前设备的当前浏览器、当前网站域名下，不支持账号登录和跨设备同步。清除网站数据会删除联系人，请定期导出备份。开发地址和线上地址的数据彼此独立。首次打开为空，不会自动写入演示联系人。
